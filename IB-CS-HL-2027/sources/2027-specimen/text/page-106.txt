             (b)                                           Award [4] max

                           Award [1] for identifying method and [1] for expansion

                           Packet filtering: a firewall inspects incoming data packets;
                           Blocking or allowing packets based on predefined rules (e.g., content, location sent from);

                           Stateful inspection: Monitors active connections;
                           Only packets that come from an established connection or session are accepted;

                           Proxy service: Firewalls can act as a proxy inspecting and forwarding packets;
                           Prevents direct access to a system,

                           Blocking unwanted traffic: Preventing access from harmful sites;
                           Configured to block data from certain locations or applications;

                           Network address translation (NAT): Presents a single, public                                          -facing IP address;
                           Making it harder for attackers to find individual systems;

                           Application layer filtering: Inspect data up to the application layer;
                           Blocking specific activities within protocols, like file uploads, instant messaging;

                           Intrusion detection and prevention: Mechanisms to identify suspicious patterns;
                           Alerting administrators or actively blocking the suspicious traffic;

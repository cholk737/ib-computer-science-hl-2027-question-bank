                                         Pre-translation: Compiled code runs faster because it has been pre                                         -translated into machine
                                         code, while interpreted code is slower due to the on-                                          the-fly interpretation;

                                         Runtime overhead: Compiled code is pre                                                                                      -compiled, so there’s no runtime overhead
                                         associated with translating source code to machine code, whereas an interpreter must parse,
                                         interpret, and translate each line or block of code in real time;

                                         Code optimization: Compilers can take advantage of the architecture’s specific capabilities
                                         (e.g., optimizing for loops, tasks), whereas interpreter does not have the full view of the
                                         program;

                                         Resource utilization: Compilers are more efficient with CPU and memory resources during
                                         execution, whereas interpreters consume more CPU cycles and memory during execution
                                         (due to the overhead of interpreting code line by line);

                                         Cache utilization: Compiled code has better cache utilization due to the compilation
                                         optimizations, whereas the interpreter itself adds an extra layer of instructions that need to be
                                         processed, leading to cache misses and slower execution.

9.     Award [2 max]
       Award [1] for stating an advantage and award [1] for an expansion.

       Use of virtual memory allows better CPU and RAM utilization/boosts multitasking/
       multiprogramming;
       multiple users or processes use the same memory (shared memory);

       Virtual memory can be cheap/ free;
       it uses the portion of a hard drive (HDD, SSD) that users already have;

       It’s nearly impossible for a system to run out of memory/ run programs larger than actual memory
       size;
       the portion of a hard drive (HDD, SSD) can be (split into equal-size chunks or segmented and)
       expanded up to a hardware limit;

       Low chance of having data loss during paging/ segmenting/ swapping memory;
       the OS keeps track of physical and virtual addresses in page tables;

       Virtual memory brings memory isolation (mechanism that isolates process memory from the kernel
       and any other processes);
       preventing spying/ accessing data/ data manipulation;

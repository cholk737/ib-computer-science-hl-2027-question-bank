       Each (wireless network) adapter has a unique label called a MAC address;

       Routers uses these addresses to identify/authenticate computers (routers include
       an option to whitelist or blacklist certain devices based on MAC addresses, so
       access could be restricted to any device which is not in the whitelist);

       One disadvantage is that the whitelist should be amended any time a new device
       is purchased / when access to guests should be granted;

       Also this method is useless against hackers who use programs which intercept
       data passing through network and report the MAC address of any device
       communicating on the network;                                                                          [4 max]

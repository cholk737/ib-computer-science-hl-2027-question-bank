                       Memory Usage
                       recursive algorithms use the call stack for each call, leading to excessive memory usage;
                       this is inefficient for simple tasks like counting through a list, especially when the list is
                       large;

                       Processing Overhead
                       each recursive call adds overhead due to repeated function calls and return handling;
